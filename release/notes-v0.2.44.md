# Sessions 0.2.44

- Claude usage limits now show in Sessions: the 5-hour and weekly windows, plus any model-specific weekly limit, read from Claude itself without starting a chat.
- An account signed in on several computers shows its allowance once, instead of the same numbers per computer.
- The sidebar is calmer: one or two lines per session, a status dot only when a session is working or needs you, and row actions on hover.
- Projects without a favicon get a two-letter mark in their own colour; an app logo is no longer mistaken for a project favicon.
- New session is a single composer: type a task, then choose Project, Agent and Access in its bar.
- Also included: calmer account, computer, settings and conversation screens built on shared controls, reversible archiving, clearer session states, and more reliable pop-out windows and delegated-session navigation.

App updates preserve existing runners and histories.
